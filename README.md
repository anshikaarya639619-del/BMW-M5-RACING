# Midnight M5 Run 🏁

A lightweight, mobile-friendly highway racing game built with plain HTML, CSS and JavaScript.

## Play locally
Open `index.html` in a modern browser.

## Controls
- Mobile: tap and hold the left/right arrows to steer.
- Nitro: hold the NITRO button to boost.
- Desktop: use ← / → or A / D; hold Shift for nitro.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish the site. The public game URL will appear in the Pages settings.

## Performance
Designed to avoid heavy frameworks and large assets. Canvas resolution is capped for lower-memory phones.
